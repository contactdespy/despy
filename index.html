Outil principal

Vérifier un SMS, un email ou un lien

Vous recevez un message qui vous semble étrange ? Notre IA analyse le texte et vous dit en quelques secondes si c'est une arnaque ou pas, avec une explication claire.

👉 Comment faire
  1. Sur la page d'accueil, descendez jusqu'à "Analyser un message"
  2. Copiez le message suspect depuis votre téléphone ou votre boîte mail (appui long → Copier)
  3. Collez-le dans le grand cadre blanc (appui long → Coller)
  4. Cliquez sur "Analyser maintenant"
  5. Vous obtenez un verdict en couleurs : vert = sûr, orange = douteux, rouge = arnaque
💡
Astuce : En version gratuite, vous avez droit à 1 analyse par semaine. Avec l'abonnement, c'est illimité.

Vérifier un numéro de téléphone

Un numéro inconnu vous a appelé ? Avant de rappeler, vérifiez-le. Despy vous dit si d'autres personnes l'ont signalé comme étant une arnaque.

👉 Comment faire
  1. Cliquez sur l'onglet "Annuaire inversé" dans la zone des outils
  2. Tapez le numéro qui vous a appelé (avec ou sans 0 devant, peu importe)
  3. Cliquez sur "Vérifier"
  4. Vous voyez en 1 coup d'œil : nombre de signalements, catégorie (arnaque téléphonique, démarchage abusif…)
⚠️
Important : Si vous avez été victime, vous pouvez vous-même signaler le numéro via le bouton "Signaler" pour aider la communauté.

Vérifier un site avant d'acheter

Vous voulez acheter quelque chose sur un site que vous ne connaissez pas ? Despy vérifie pour vous : depuis combien de temps il existe, s'il a bonne réputation, et si c'est un site sécurisé.

👉 Comment faire
  1. Cliquez sur l'onglet "Vérificateur de site"
  2. Copiez l'adresse complète du site (par exemple https://...)
  3. Collez-la dans le cadre
  4. Cliquez sur "Vérifier ce site"
  5. En 10 secondes, vous obtenez un rapport : ancienneté, sécurité du paiement, certificat, avis détectés

Vérifier si votre email a été piraté

On l'appelle "dark web" : c'est la partie cachée d'Internet où les pirates revendent les emails et mots de passe volés. Despy vérifie si VOTRE email apparaît dans ces fuites pour vous prévenir.

👉 Comment faire
  1. Connectez-vous à votre compte Despy
  2. Allez dans "Mon espace" → "Protection"
  3. Cliquez sur "Vérifier mon email"
  4. Vous obtenez la liste des fuites où votre email apparaît
  5. Pour chaque fuite, vous avez la marche à suivre (changer votre mot de passe sur tel ou tel site)
🔒
100% sécurisé : on ne stocke jamais vos mots de passe. La vérification se fait par cryptographie anonyme.
